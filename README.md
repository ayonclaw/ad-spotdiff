# Brasswater Conservatory
A quiet, offline spot-the-difference game in a botanical glasshouse.
Run `MAKEFUN_OUTPUT_DIR=out node main.ts`, then serve `out/game` with any static HTTP server.
Click changed details in either picture. Wrong guesses add penalties; H gives a hint for two penalties.
Use Tab, arrow keys and Enter for keyboard inspection; Shift makes arrows precise. R restarts.
Build runtime: Node 22.18 or later, standard library only. Five deterministic differences.
